How it works

Three quick steps to protect your code.

1

Add your source

Paste JavaScript or select a local .js file. The library supports source up to about 2.1 MB.

2

Choose domain lock

Leave it unchecked for regular obfuscation, or enter one or more domains and enable the lock.

3

Protect and export

Press Protect JavaScript, review the generated output, then copy or download it.

FAQ

Does this website need hosting?

No. Save index.html and assets/JSArmor.js together and open index.html. An internet connection is needed to load the obfuscator dependency from jsDelivr.

Does domain lock guarantee my code cannot be copied?

No. It is a client-side restriction, not a security boundary. Treat all browser-delivered code as inspectable.

Why can obfuscation fail to load?

The uploaded library dynamically loads JavaScriptObfuscator from jsDelivr. Check internet access, CDN availability, and browser console errors.
